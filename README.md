# Odd or Even Checker (C++)

**Course:** COS 201 / CSC 207
**Assignment:** Write a C++ program to check if a number is Odd or Even.

## How it works

The program asks the user for a whole number and uses the modulus operator (`%`) to find the remainder when the number is divided by 2:

- remainder is `0` → the number is **Even**
- otherwise → the number is **Odd**

It also handles negative numbers and asks again if the input is not a valid whole number.

## Sample output

```
Enter an integer: 7
7 is an Odd number.
```

```
Enter an integer: 24
24 is an Even number.
```
